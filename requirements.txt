# AIBOM-Guard runtime dependencies.
#
# This file is what the project itself needs to run:
#     pip install -r requirements.txt
#
# pyproject.toml's [project].dependencies is the canonical list - that is what
# `pip install aibom-guard` resolves. This file mirrors it with the reasoning
# attached, for people installing from a clone. tests/test_packaging.py fails
# if the two ever drift apart.
#
# It is NOT the scan input. The example packages that used to live here
# (requests==2.28.0, numpy==1.24.0, pyyaml==5.3.1) are pinned to deliberately
# vulnerable versions so the scanner has something to find - installing them
# was never the intent. They now live in examples/sample-requirements.txt:
#     aibom-guard examples/sample-requirements.txt
